## 验收结论

M0 未通过，M1 不开始。WPF 透明区在限定的合成输入场景中领先；WinUI 透明区实测失败。视觉只有一个浅色 WPF 合成样例，没有背景模糊证据。DWM 被动探针只证实全局 API 可采样；它没有 Dock 进程帧时序。DPI/多屏、任务栏/全屏、托盘、配置恢复和呈现时间仍不完整。基线 CI 与指定 SHA 干净克隆已通过，但不能替代本轮修改的精确 SHA 远程验证。

输入证据由 SendInput 合成，并由独立下层窗口过程和 Dock 事件日志确认接收方；不是物理鼠标手工验收。本轮没有启动桌面交互。今后的输入/视觉/窗口交互/显示模式测试须先获得用户对具体范围的明确同意；脚本安全保护尚未经过端到端桌面测试。
