# 项目负责人决策清单

状态：**待负责人评审；以下推荐仅供选择，不写入已批准默认值。** Apple 官方资料不能替项目确定 Windows 首次运行体验。每项只在本清单集中列一次；决定后记录选项和日期，不在各文档重复询问。

| ID | 问题与现有证据 | 推荐方案 | 其他合理选择 | 影响 |
|---|---|---|---|---|
| D-01 | Windows 首次运行是否默认固定文件管理器？Apple 指南以 Finder 为打开 App 的示例，但不证明 Finder 是通用默认固定项。Windows 端 Explorer 映射尚属建议。 | 默认放入 Explorer 文件管理角色，明确是 Windows 映射；图标取系统资源。 | 首次运行不固定文件管理器；允许用户手动添加。 | 默认熟悉度与类 macOS 首屏相似度；决定 DOCK-021 与初始排序。 |
| D-02 | 最近/建议应用是否默认显示？Apple 文档支持最多三项和设置开关，但没有确认所有设备的默认开关状态；Windows 历史来源尚未确定。 | 默认关闭；用户开启后只保留本机最少必要状态、最多三项、可关闭并清除。 | 默认开启并提供首次说明、立即关闭和清除入口。 | 隐私默认、初次界面复杂度和 Windows 历史记录实现成本；影响 DOCK-009/036。 |
| D-03 | Windows 任务栏不变时，Dock 首次显示在哪一边、如何避免重叠？macOS 文档不能决定 Windows 任务栏策略。 | 不改任务栏设置；首轮默认右边缘以避开通常位于底部的任务栏，用户可切换底部/左侧并设置隐藏策略。 | 默认底部并与任务栏并存；默认底部自动隐藏；让用户启动时选择位置。 | 默认观感与避免遮挡之间取舍；决定首启布局、工作区保留策略和自动隐藏默认值。 |
| D-04 | 用户能否隐藏/替换功能区或系统项目？固定 App、可选近期区、文件/文件夹区是官方语义归纳；Windows 首发组成尚未批准。 | 保留对象语义分区；允许隐藏近期区、移除可选系统角色项和自定义文件/文件夹，不允许误删项目本体。 | 三个区域固定且不可隐藏；或允许用户重排/替换全部区域。 | 灵活性、结构保真和布局复杂度；影响 DOCK-001、021–029、036。 |
| D-05 | macOS 行为与 Windows 安全/平台规则冲突时，产品优先级是什么？Apple 的 modifier/fullscreen 语义不等于 Windows 能力。 | 保留用户可见意图；遇前台限制、独占全屏、隐私或无障碍冲突时遵守 Windows 规则，并明确说明是兼容映射。 | 尽可能严格复刻 macOS 输入/外观，即使需要更强适配；或完全采用 Windows 原生语义。 | 影响键位、焦点策略、全屏行为、无障碍和可维护性；决定 DOCK-013、017、018、037、041。 |
| D-06 | 清空 Recycle Bin 是否每次要求确认？Apple 指南显示清空警告，并允许按次或在设置中关闭警告；清空后永久删除。 | 每次明确确认；失败不回退到永久删除，提供取消。 | 允许用户在设置中关闭确认，首次仍启用。 | 数据安全与操作效率；DOCK-028/029 为 Trash 功能发布门槛。 |
| D-07 | Option/Command-click 等 macOS modifier 是否映射到 Windows？Apple 明确记录 Option-click 与 Option-Command-click 语义，但 Windows 键位与系统快捷键冲突。 | 首发不默认映射；高级设置中允许用户逐项绑定可逆操作，并清楚显示范围。 | Option→Alt、Command→Ctrl/Win 的兼容预设；或完全不提供这些语义。 | 用户熟悉度与误触/系统快捷键冲突；影响 DOCK-017/018。 |
| D-08 | Dock 外观跟随 Windows 明暗主题还是独立选择？Apple 有系统 Light/Dark/Auto 外观页面，但该来源不是 Dock 专项材质规范。 | 默认跟随 Windows 系统明暗；允许独立覆盖，保持对比度；视觉参数以后由 Mac 样本校准。 | 固定单一 Dock 外观；或提供独立浅/深主题而不跟系统切换。 | 用户预期、无障碍对比和材质调校范围；影响 DOCK-003/042。 |
| D-09 | 是否接受当前 P0/P1/P2 排期提案？分级不改原 ID、原需求和原阶段；Trash 项列 P1，但其数据安全验收是该功能发布时的硬门槛。 | 接受提案为开发顺序参考，逐阶段仍按原需求验收。 | 调整单项优先级，或要求 Trash 进入首批可运行版本。 | 影响工作包顺序和初始切片范围；不会把任何未测功能改成 PASS 或从原阶段删除。 |

许可证仍是独立的公开发行治理事项，本清单不要求现在决定，也不修改 `LICENSE`。
