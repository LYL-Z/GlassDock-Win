# M1 实施任务书：macOS Dock 参考采样与产品规格冻结

状态：**M1 规格研究工作线已启动，规格仍为草案；M1 未验收、未冻结。** 依据 2026-10-23 阶段依赖变更，官方资料归集、46 项需求初稿、采样方案、素材权利台账和平台映射可以与 M0 并行。M0 的 NO-GO 不变；生产渲染器、Windows Dock 行为实现及依赖最终 HWND/Composition 决策的工作仍须等待 M0 GO，或等待负责人批准明确范围与期限的 CONDITIONAL GO。本任务书依据原任务书 `01_macOS_Dock参考采样与需求冻结.md`，保留原 SPEC/REF ID 和后续阶段功能范围。

## 目标与边界

形成可追溯、可重复、可实现的 macOS Dock 行为/视觉规格与 Windows 映射，为 M2 Core 和 M3 窗口宿主提供冻结输入。目标产品仍为尽可能 1:1 复刻 macOS Dock 的外貌、图标、Liquid Glass、动画、交互与系统整合。M1 只测量和写规格，不将 Windows PoC 半透明效果当成产品视觉，也不创建完整 Dock 功能。

## 可并行启动的规格线

无需最终 Windows 技术选型即可开展：

1. 复核 Apple 官方用户指南与人机界面指南，记录页面日期、版本及其只支持的语义范围。
2. 将原任务书 DOCK-001–046 导入初步矩阵，保留原描述、类别、原阶段和源 ID；为 Windows 目标写可讨论的行为草案。
3. 定义 REF-01–07 采样条件、元数据和评估方法；没有 Mac 实机时将实机观察逐项保持 `NOT TESTED`。
4. 审核公开来源、可分发原创素材、第三方图标/品牌授权；不把项目代码许可证当成素材授权。
5. 写 Dock 结构、项目类型、输入语义、放大/弹跳/指示/自动隐藏的候选验收规则，并明确哪些待 Mac 样本确认。

## 实施线门禁

以下工作仍依赖 M0 技术结论或负责人对风险的明确批准：

1. 生产 HWND 宿主、输入区域/焦点策略和渲染后端实现；M0 当前 NO-GO，尚无最终路线 ADR。
2. 将草案视觉 token 宣称为实测值、实现或验收 Liquid Glass、实现 M3–M11 功能。
3. 将规格标为冻结、将 M1 标为完成，或将未观察项目标为 PASS。

实机参考样本是 M1 视觉/行为冻结的独立门槛。当前没有获授权的 Mac 实机截图、录屏或系统档案，因此官方文档研究可以前进，但 REF 样本、像素参数和依赖实机的规格冻结仍未完成。阶段调整依据见 [M0/M1 并行工作线变更记录](M0-M1-parallel-work-change-2026-10-23.md)。

## 工作包与顺序

### M1.1 来源与 46 项映射（SPEC-01）

- 将 DOCK-001–046 转为可测试条目；每条保留原 ID、原描述、阶段、Apple 官方描述来源、实机观察、Windows 映射、实现可行性、优先级、验收方式和状态。
- 官方文档陈述与 Mac 实机观察分列；一个证据不能替代另一类。
- 遇到用户自定义 Dock 内容或地区/应用差异，记录变量，不把单一机器状态定义为普遍默认。

### M1.2 版本与样本定义（SPEC-02）

- 原始任务书指定 macOS 27 为目标基线；取得真实设备后记录系统 build、设备类型、Dock 偏好、安装应用/地区和时间。当前只有 Apple 官网 macOS 27 文档页面，不代表已有相应设备或 build 样本。
- 描述默认 Dock 图标组成的可变性；截图只代表注明配置的一台设备和时间点。

### M1.3 参考采样矩阵（SPEC-03、REF-01–07）

| 参考 ID | 场景 | 记录量 |
|---|---|---|
| REF-01 | 浅/深外观与浅/深壁纸，底/左/右位置 | 背板边界、曲率、阴影、边缘、分隔线、指示点、基线 |
| REF-02 | Finder/系统项、第三方 app、最近 app、Downloads、Trash、文件夹 | 图像、透明像素、色彩、外接框、基线、状态 |
| REF-03 | 放大，60/120Hz；慢/快移动、边缘/密度变化 | 峰值、影响半径、邻居位移、插值、边缘钳制、命中 |
| REF-04 | 未运行/启动/后台/前台/多窗口/最小化/退出 | 指示点、弹跳、切换/菜单、最近项变化 |
| REF-05 | 应用入栏/离栏/重排、文件投放、文件夹 Stack | 幽灵、吸附、滚动、禁止/接受反馈 |
| REF-06 | 自动隐藏、全屏、双屏、虚拟桌面、睡眠恢复 | 唤出、动画、归属、z-order、恢复 |
| REF-07 | 键盘、读屏、减弱动态效果 | 焦点框、可访问名称/状态、动画降级 |

每个实际观察写设备、系统、用户偏好、具体动作、取样方法和原始证据路径。无法复现的细节标 `NOT TESTED` 或 `BLOCKED`。

### M1.4 素材与权利台账（SPEC-04）

- 分开记录本地研究参考素材、项目可分发原创素材、第三方应用/品牌素材。
- 保存权利人、授权范围、来源链接、署名/再分发约束及删除/替换责任人。
- Apple 系统图标/品牌资源无分发许可时，只可本地参考，不将其作为安装包必需内容。项目 LICENSE 不授予第三方素材权利。
- 当前状态和逐项登记见 [素材权利与采样台账](rights-and-reference-ledger.md)；本轮没有引入任何 Apple/第三方图像或私人截图。

### M1.5 测试机档案与基线（SPEC-05）

- 将 M0 的 Windows WPF/WinUI 启动和可复现性能日志标为新工程 PoC 基线，不代表历史版本，也不代表最终渲染性能。
- 为目标 Windows 构建/测试机器记录 OS build、CPU/GPU、驱动、RAM、显示器、DPI、刷新模式、运行模式、commit SHA 与配置。
- 分开记录逻辑更新、框架渲染回调、DWM 全局合成、进程 GPU 指标和真实输出；未知值不推断。

### M1.6 规格评审与冻结

- 为每个功能写用户触发、状态前置条件、预期视觉/行为、边界情形、Windows 映射、拒绝/降级情形和可验证的验收标准。
- 评审所有 46 ID 的归属、依赖、优先级、素材限制和风险。
- 在负责人批准冻结前，使用 `docs/dock-evidence/M1/spec-matrix.csv` 作为可审阅草案。将来冻结时连同设计规格、状态图、参考索引和变更日志版本化提交，不覆盖原始证据。

4. [素材权利与参考样本台账](rights-and-reference-ledger.md)；每种 Apple/第三方素材独立留权利记录。

6. SPEC 冻结签署记录与可复现 commit。

## DoD / 验收

- SPEC-01–05 全部有条目状态和可追溯证据；不允许空 ID、不允许隐含默认值。
- 46 项功能均保留原 ID/阶段并有优先级、Windows 映射和验收入口。
- REF-01 底部浅/深、REF-03 放大、REF-01 三分区、REF-05 点击/拖放、REF-06 自动隐藏至少有可复现实机样本；Mac 不可得时列精确缺口并由项目负责人接受阶段风险后才可冻结。
- 每个捕获可由设备档案复现；匿名/公开插图先单独审核隐私与素材权利。
- M1 结束前不开发 M4 的最终材质，不因视觉或素材未定而伪称达到 1:1。

## 顺序与依赖

先做官方来源归集和设备档案，再定义样本矩阵；随后进行 REF-01..07 实机采样并逐条回填 46 功能 ID；再做 Windows 映射和素材审查；最后评审、冻结规格并产生 M2/M3 的输入任务。若目标 Mac 设备不可用，先把能做的规格和 Windows API 分析做完，剩余设备依赖单列，不虚构采样。
