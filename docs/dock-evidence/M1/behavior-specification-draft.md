# GlassDock-Win 产品行为规格草案（M1 研究线）

状态：**M1 PROVISIONAL，尚未 Mac 实机采样或最终冻结。** 本文把官方公开行为转成 Windows 产品规格。2026-10-23 负责人已批准 D-01～D-09 产品政策；这些决定仅适用于 GlassDock-Win，不是 Apple 官方默认或已实现功能。

## Dock 的区域与对象

首次运行项目目录另见 [默认项目与功能目录](default-item-catalog.md)：Apple 公开语义、Windows 映射候选和产品决策待定项分别记录。

### 区域模型（提案）

1. **App 区：** 固定应用快捷方式；点击启动或依据运行状态尝试激活，不卸载/删除目标应用。用户可排序、固定/取消固定。
2. **建议/近期区：** Windows 默认启用；仅显示有可靠本地观察来源的近期 App，按稳定 App 身份去重，最多三个且排除固定项。没有来源时为空；不上传使用记录，用户可关闭和清除。Apple 资料只支持最多三个未固定近期 App 的语义，不证明 Windows 行为或 Apple 的普遍默认值。
3. **文件区：** 与 App 区区分；包含用户添加的文件/文件夹代理、Downloads 和 Trash 角色项。拖出 Dock 移除引用与把文件拖入 Trash 是不同操作。
4. **临时项：** 如未来 Handoff 角色，只有存在用户主动启用且权限合规的跨设备来源才可显示；否则隐藏。
5. **分隔符：** 表示语义边界而非装饰。Windows 默认 Dock 边缘为底部；左/右位置可由用户调整。遇任务栏空间冲突时不修改任务栏设置，由 Dock 自身兼容策略和用户选择处理。准确分隔线样式、端点和相对间距等 Mac 实机数据缺失，当前未定。

## 条目状态和操作（提案）

| 项目类型/状态 | 输入 | 产品目标 | 未决或失败边界 |
|---|---|---|---|
| 固定 App，未运行 | 单击 | 启动选中的 Windows App/桌面程序；启动请求只触发一次 | 包应用与传统快捷方式身份匹配尚待 M6；启动失败必须反馈 |
| 固定 App，正在运行 | 单击/次级点击 | 优先请求激活其最近使用窗口；次级菜单可列可验证的窗口和应用命令 | Windows 前台切换受系统规则约束；不承诺强制抢焦点 |
| App 启动中 | 系统状态反馈 | 可播放有限时长启动动效；最终运行状态以窗口/应用标识确认 | 动画和运行状态需解耦；超时后停止装饰并报告错误 |
| 运行 App | 指示点 | 视觉点表示存在匹配的打开应用/窗口；显示开关只控制装饰，不改变运行状态 | 需要定义 UWP/多窗口/权限边界和 AppUserModelID 归并 |
| 多窗口 App | 单击/次级点击 | 有明确的激活目标；次级菜单可选窗口 | 具体窗口菜单和排序需 Mac 实测与 Windows 可达性设计 |
| 文件/文件夹代理 | 单击/拖动 | 文件用 Shell 关联打开；文件夹可展开 Stack 或打开资源管理器 | 权限、断链、云占位、网络位置必须可恢复 |
| Downloads | 单击/次级点击 | 指向 Windows Known Folder API 返回的真实 Downloads 路径，可显示 folder/stack | 不猜路径、不复制文件；用户重定向/同步盘需支持 |
| Stack | 单击/次级点击/键盘 | 展开可选 Fan/Grid/List 视图；排序和项目选择可访问 | 样式、最大项数、屏幕边界和排序默认待实机验证 |
| Trash | 单击/拖入/次级点击 | 打开回收站；拖入文件使用可恢复 Shell 回收语义；清空必须明确确认，首发不提供跳过确认选项 | 无法回收的卷/路径明确拒绝，绝不静默永久删除；Core 不执行回收站操作 |
| 最小化代理 | 单击/次级点击 | 恢复明确对应窗口；是否归到应用项或独立文件区按用户设置 | 对第三方应用的原生最小化动画不声称由 Dock 控制 |
| 拖拽重排 | 按住/移动/释放 | 明确拖动阈值、插入反馈、可取消；拖出只移除快捷方式/代理 | DnD 文件投递使用 Shell/OLE；不可投递则拒绝并说明 |

## 特殊项目与状态的验收边界

以下是可据官方资料写入行为草案的语义，Windows 操作是产品映射，不代表 Apple 行为，也尚未在 Mac 实机观察：

| 行为 | 官方资料支持的语义 | Windows 草案及验收边界 |
|---|---|---|
| 三个功能区 | 固定 App、未固定的近期 App、文件/文件夹项目由分隔语义区分；近期 App 最多三项。来源 A1、A10 | 保持 App / optional recent / files 三类对象，不因窗口方向改变对象身份。具体轴向、分隔符坐标与首次运行默认项目待 REF-01/02 与用户评审 |
| App 启动与状态 | 点击图标可打开 App；设置页分别控制启动时图标弹跳和打开 App 指示点。来源 A1、A2 | Launch、已运行 App 激活和多窗口选择是不同命令；启动动画不代替运行状态，前台请求遵守 Windows foreground policy |
| Stack | Downloads 是 Dock 默认文件夹角色；文件夹可显示为 Folder/Stack，按 Fan/Grid/List 查看及排序。展开后可打开项目或在 Finder 中打开，点击桌面或同一 Stack 可收起。来源 A3 | 使用 Known Folder 的实际 Downloads 路径；点击项目走 Windows Shell；“Open in Explorer”是 Windows 映射。路径失败显示错误，不复制/扫描目录；视图、排序和折叠必须可由键盘操作 |
| Trash/Bin | 放入 Trash 的项目在清空前仍可取回；清空会有警告，清空后永久删除。来源 A14。AppKit 有空/满图像资源名，见 A13，但切换外观仍未实机观察 | 对应 Windows Recycle Bin；打开、拖入与清空分别建模。清空需确认；拖入只调用可恢复 Shell 语义；不能处理时拒绝并保留源文件 |
| 自动隐藏与全屏 | macOS Dock 设置支持边缘自动显示/隐藏；Apple 全屏帮助所述为 macOS 应用全屏，不是 Windows DXGI 独占。来源 A2、A7 | Windows 最大化、无边框全屏、DXGI 独占分开处理；不得要求 Dock 覆盖独占画面，不抢焦点、不干扰输入，离开状态后恢复先前策略。遵守系统焦点、安全与无障碍规则，不采用不稳定绕过 |
| 键盘与无障碍 | Apple 指南给出键盘进入 Dock、左右移动和 Return 打开。来源 A1 | 使用 UI Automation 提供名称、角色、状态和焦点；鼠标不可用时仍能到达应用、文件、Stack 与菜单核心动作。macOS 特殊组合键不默认映射，后续仅提供可配置高级方案 |

## 已批准的 Windows 产品政策（2026-10-23）

- 首次运行包含 Explorer 功能映射；底部为默认边缘；近期区默认启用但无真实本地历史时保持空。
- 最近记录仅存本机实现所需数据，不上传；用户可关闭和清除。此政策不授权读取/上传私人历史，也不证明已有真实 Windows 活动来源。
- 保留固定 App、近期 App、文件/文件夹的核心语义区并允许合理自定义；移除项目仅移除 Dock 引用，不删除目标。
- 清空 Recycle Bin 首发必须明确确认且不能默认关闭；Windows 焦点、安全、全屏和无障碍规则优先于危险的强制复刻。
- Dock 跟随 Windows 明暗主题为默认，允许独立设置。准确材质参数继续等待 Mac 实机数据；不得用此主题决定宣称 Liquid Glass 已实现。
- D-09 接受 P0/P1/P2 当前建议作为排期参考，负责人保留后续调整权；原 46 项和阶段要求不删减。

决策来源与 ID 映射见 [负责人决策记录](owner-decisions.md)。首启 Downloads/Recycle Bin 是否默认出现、任务栏冲突时的具体提示流程以及近期 Windows provider 均未被本轮决定或实现。

以上行为的逐项 Given/When/Then 验收检查、依赖与优先级见 [DOCK-001–046 矩阵](spec-matrix.csv)。这张表只建立产品验收入口；任何 Mac 特有视觉参数、状态时序、默认设置和行为差异仍需 REF 样本，当前均为 NOT TESTED。

## 动态反馈和运动（提案；参数待实测）

- **Hover 放大：** 连续位置输入影响邻近图标，命中目标跟随实际可视槽位，图标沿共同基线缩放。M1 先记录峰值、影响半径、边缘行为、邻居让位与时序，不先把 Gaussian 函数或某个毫秒数写成 Apple 算法。
- **启动弹跳：** 仅在用户开启且应用实际启动请求中短暂播放；关闭、启动失败、减少动态效果或低功耗时停止/降级。
- **运行指示：** 对应 App 状态独立于启动动画；用户关闭指示点不应隐藏运行状态的其他辅助入口。
- **Tooltip/菜单：** 出现延迟和关闭行为待 REF-04/REF-07 采样；菜单打开、键盘焦点、拖放期间不能突然自动隐藏 Dock。
- **自动隐藏：** Visible、InteractionHold、HidePending、HiddenAuto、FullscreenSuppressed、SystemSuppressed、Recovering 的状态及优先级写入 M9 规格；离开全屏回到用户原偏好，不依赖手动重启。
- **减少动态效果：** 支持 Windows 系统或应用可访问设置；动画降级不妨碍键盘和鼠标完成操作。

## 初步视觉构成（不作为 M4 实现规格）

将未来可校准层分为：窗口几何/命中区、外部背景源、背景模糊与色调、圆角遮罩、细边高光、投影、图标/徽标、分隔符、tooltip/menu。对每层记录 Mac 实测值及 Windows 实现，不用单一不透明度值替代背景模糊，也不把 Windows Acrylic 命名为 Liquid Glass。Apple 的图标层效果指导不构成 Dock 背板的视觉规范。

## 验收定义

当前提案每一项后续都要补成可执行 Given/When/Then：前置状态、用户动作、预期状态迁移、可见反馈、取消/错误行为、键盘/UIA 表示、Windows 映射、Mac 源和证据路径。没有实机参考的视觉/时序值保持 `NOT TESTED`；没有代码实现的行为保持 `NOT STARTED`。阶段归属和 ID 见 [46 项初步规格矩阵](spec-matrix.csv)。
