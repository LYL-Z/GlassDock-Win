# Dock 默认项目与功能目录（M1 草案）

状态：**产品提案，未冻结；没有 Mac 实机默认 Dock 样本。** 本文区分 Apple 公开说明、当前可复述的语义和 GlassDock 首次运行建议；不把某张官网插图或常见应用排列说成所有 Mac 的默认图标清单。

## 参考事实与项目候选

### 原生 Dock 的功能区与默认项目边界

Apple 用户指南当前说明 Dock 可以显示最多三个尚未固定的近期 App，并附带 Downloads 文件夹；页面用 Safari、Bin 作为常用 app/feature 示例，并以 Finder 说明从 Dock 打开 App。设置页明确列出尺寸、放大、三边位置、最小化、自动隐藏、打开动画、运行指示和近期项开关。文件夹指南确认 Downloads、Folder/Stack、Fan/Grid/List 与排序语义。**这些来源没有给出一份适用于所有 Mac、版本和用户配置的完整默认图标顺序清单。** 本项目没有 Mac 设备样本，故不把官网插图或常见配置当成实机默认值。来源与边界见 [官方资料笔记](official-reference-notes-2026-10-23.md) A1–A3、A10、A13–A14。

三分区是当前产品结构提案，对 Apple 文档的语义归纳，不是对每种 Dock 外观的逐像素断言：

1. **固定 App 区：** 用户保留的 App 快捷方式；Apple 文档描述将 App 固定在近期 App 分隔线一侧。
2. **建议/近期 App 区：** 可选、与固定项去重；官方用户指南记录最多三个未固定近期 App。Windows 的数据来源、保留策略与首次运行开关仍需产品决定。
3. **文件与文件夹区：** 用户文件/文件夹、Downloads、Trash/Bin 等；Apple 文档描述文件/文件夹位于另一条分隔线的文件侧。各方向中的准确视觉方向、分隔线形状及位置须由 REF-01/02 实机样本确认。

对于窗口的原生 Dock 图标，Windows 映射采用“系统提供的当前 App 图标 + 可访问状态装饰”方案；macOS 图标、Finder/Safari 品牌和 Apple 系统截图不作为 Windows 产品资源。Apple AppKit 文档列出空/满 Trash 图像资源名，但这只证明 API 有这些标准图像标识，不替代 Mac Dock 实机观察其具体切换时机或外观。

### Windows 首次运行组成提案（未批准、未冻结）

| 首次运行元素 | 临时建议 | 用户影响与待决项 |
|---|---|---|
| Windows 文件管理入口 | 使用 Explorer/Shell 当前图标和受支持启动入口，明确称为文件管理器映射 | 不显示 Finder 名称或复制 Finder 图像；是否默认固定属于产品决定 |
| 用户固定 App | 空区开始，不预先挑选浏览器、办公、媒体等第三方 App | 避免随包带入不必要的应用品牌和图标；用户主动固定后读取其合法系统图标 |
| 近期 App | 推荐候选为首次运行默认关闭，须由负责人按 D-02 决定 | 如启用，严格限制为最多三项、排除已固定 App，并提供关闭/清除规则 |
| Downloads | 使用 Windows Known Folder 当前路径作为角色项 | 用户重定向、同步位置及访问失败必须保留正确语义 |
| Trash/Bin | 使用 Windows Recycle Bin Shell 对象、图标与空/非空/未知状态 | 不模仿 Apple 图标；清空需要确认；拖入失败不能退化为永久删除 |
| 文件夹与其他文件 | 首次运行不添加私人目录，由用户选择 | 不扫描或复制用户文件；Stack 的显示和排序由用户选择 |
| Handoff 与 Apple 专属角色 | 默认不显示 | 只有未来存在真实、获授权且跨平台支持的服务时，另行评估 |

临时顺序提案：文件管理入口 / 用户固定 App →（可选）近期 App → 分隔符 → 用户文件与文件夹 / Downloads / Recycle Bin。App 区可以为空。此顺序不冻结图标数量、尺寸、间隔或边缘方向。

| 语义角色 | Apple 公开资料支持的内容 | GlassDock 首次运行候选 | 功能与边界 | 关联需求 |
|---|---|---|---|---|
| Finder / 文件管理入口 | Apple 用户指南以 Finder 作为 Dock 中可打开的 app 示例；默认固定项目的完整顺序仍需实机采样 | 固定一个 Windows 文件管理入口（Explorer），图标取自本机 Shell，不复制 Finder 图像或名称 | 单击打开文件管理器；快捷菜单和“定位文件”分别定义；不宣称与 Finder 完全等价 | DOCK-012、019、021 |

| 近期/建议 App | Apple 公开指南说可显示最多三个、且尚未固定的近期 App；设置页提供开关。精确默认开关值不由本资料集确认 | 提供独立设置，默认值待负责人结合 Mac 样本/隐私决策确认；只用本应用可解释的本机运行状态，不承诺复制 Apple 排序算法 | 已固定 App 不重复；最多三项；清除或关闭时不影响固定区 | DOCK-009、036 |

| Trash / Bin | Apple 指南将 Trash/Bin 作为 Dock 项；AppKit 提供 empty/full 图像名称（A13），但具体 Dock 图标状态切换未在本机观察 | 映射 Windows Recycle Bin Shell object；使用本机系统图标 | 单击打开；状态反映回收站内容；“清空”单独确认；移动文件优先走可恢复回收语义，拒绝静默永久删除 | DOCK-027–029 |
| 文件夹与用户 Stack | Apple 允许用户添加文件夹，文件夹或 Stack 可用 Fan/Grid/List 展开并排序 | 首次运行不自动加用户私人目录；由用户选文件夹后保存引用 | 列表内容受路径权限/云占位状态约束；不得为了展示而递归扫描未选择目录 | DOCK-022、024–026 |
| 最近窗口/最小化代理 | Apple 文档与原始矩阵包含多窗口、最小化窗口代理和最近项菜单 | 不作为必备首次运行图标；后续由用户偏好控制 | 每个代理需稳定对应 HWND/App identity；关闭代理不能关闭应用或删文件，除非该命令明确确认 | DOCK-014、030–031、045 |
| Handoff 等临时跨设备项 | Apple 文档记载兼容 Handoff 的活动可出现在 Dock；它依赖 Apple 设备/账户生态 | Windows 首次运行不显示；后续只在有用户授权且具备真实跨设备来源时设计 | 不伪造最近文件/手机状态；无来源时隐藏，不以占位图冒充可用功能 | DOCK-039 |

## 初始排序提案

候选排序为：**（若负责人选择默认固定 Explorer）Explorer 文件管理入口 → 用户固定 App 区 → 可选近期区 → 分隔符 → 用户文件/文件夹区 → Downloads → Recycle Bin**。这不是已批准的默认 profile。D-01 决定 Explorer 是否首次固定；D-02 决定近期区默认值；D-03 决定初始边缘和任务栏共存。只记录语义分区候选，不冻结具体坐标、分隔线样式或像素间距；Windows 首发不捆绑第三方品牌图标。

左/右 Dock 沿主轴旋转但保留 App 区、近期区、文件区语义顺序的方向映射，须通过 REF-01 实机确认。底部的“左侧/右侧分隔线”在纵向边缘如何呈现也未测。

## 图标来源和显示状态

- 已安装 Windows App 优先使用系统返回的当前 App 图标；快捷方式文件使用 Shell 提供的图标。不得从 Apple 系统文件中提取 macOS 图标。
- Finder、Safari、Launchpad 等名称和图像不作为 Windows 实装资源；需要说明功能映射时用文字说明“类比”并区分品牌。
- 最近/运行/徽标/弹跳是叠加状态，不创建第二份基础图标；优先级、遮挡和无障碍名称需后续规格评审。
- 当前资源包：无。新增任何第三方或 Apple 图像前，先登记权利人、来源、许可范围、署名义务和再分发许可。
