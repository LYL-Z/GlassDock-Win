# Contributing

This repository is a new, local-only prototype. Keep platform APIs behind the Windows adapter and keep dock state and layout calculations independent of UI frameworks.

Before each milestone, record the requirements, commands, exit codes, screenshots, known risks, and rollback steps under `docs/dock-evidence/Mxx/`. Do not claim a UI or device behavior is verified unless it was exercised on the stated Windows build.

Do not add unreviewed packages, Apple system assets, or credentials. License and remote repository choices remain with the project owner.
